# 🌱 AgriMart - Certified Smart Agricultural Input & Advisory Platform

![License](https://img.shields.io/badge/License-MIT-d97706?style=for-the-badge)
![Status](https://img.shields.io/badge/Status-Demo_Ready-0284c7?style=for-the-badge)

AgriMart is a feature-rich, modern agricultural web application built to empower farmers with genuine government-certified inputs (seeds, fertilizers, pesticides), precision soil-based dosage calculations, AI crop disease diagnostics, village bulk buying discounts, and Kisan Credit EMI options.

---

## ✨ Key Features

- 🌾 **14+ Certified Seed Varieties & Inputs**: High-yield Paddy, Wheat, Bt Cotton, Hybrid Maize, Groundnut, Soybean, Chilli, Onion, Brinjal, Okra, Tomato, and Sugarcane.
- 📱 **QR Code Authenticity Verification**: Built-in verification scanner modal displaying government certification lab codes, purity ratings, and batch details to fight counterfeit products.
- 🧮 **Precision Crop & Soil Advisory Engine**: Calculates exact Urea bags, DAP bags, seed kg, and spray dosages tailored by crop, soil type, and land acreage.
- 🔬 **AI Crop Disease Doctor**: Instant disease diagnosis (e.g., Rice Leaf Blast, Cotton Bollworm, Wheat Rust) with symptoms detection and 1-click certified pesticide recommendations.
- 👥 **Village Hub Group Buying (18% Savings)**: Bulk ordering delivered to local pickup hubs (*Anandpur Village Hub*) to cut shipping costs and unlock pooled discounts.
- 🎙️ **Multi-Language & Voice Assistant**: Voice search simulation and multi-language support (English, Hindi, Telugu, Tamil, Marathi, Punjabi, Bengali, Kannada).
- 💳 **Kisan Credit EMI ("Pay After Harvest")**: Flexible 0%-interest seasonal credit payment option backed by microfinance partners.
- 🚜 **Closed-Loop Sell Harvest Marketplace**: Farmers list upcoming harvest yields to lock in guaranteed Minimum Support Price (MSP) buyback contracts.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System, Glassmorphism, CSS Variables, Responsive Flex/Grid), ES6+ JavaScript.
- **Server**: Native PowerShell HttpListener & Node.js HTTP Server (`server.ps1` / `server.js`).

---

## 🚀 How to Run Locally

### Option 1: Open Directly
Double click `index.html` or drag it into any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Run Localhost Server
Run using PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Or open **http://localhost:8080/** in your browser.
